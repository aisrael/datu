datu-wasm · conversion example

Inspect a Parquet or Avro file in the browser

Drop in a .parquet or .avro file and inspect its embedded metadata, schema, and a paginated preview of its rows — entirely client-side, via the datu-wasm package built by wasm-pack. See crates/datu-wasm/examples/conversion/README.md for how to build and serve this.

— — —
Built with wasm-pack build crates/datu-wasm --target web --out-dir crates/datu-wasm/pkg. The preview tab converts the whole file to JSON client-side and paginates it in memory — fine for this demo, not meant for huge files.
